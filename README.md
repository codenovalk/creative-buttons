## How to use

1. Download the `.html` file of the button you like.
2. Open it in your browser. That's it.
3. To use it on your own site, copy the button's HTML, the `<style>` and the `<script>` into your page.

Each file includes **Auto-loop** and **Recording mode** buttons, so you can screen-record a clean clip.
